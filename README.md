# Q1 - Data Pipeline and SQL Analysis

## Overview

This project scrapes book data from Books to Scrape using
Requests and BeautifulSoup, cleans the data using pandas,
stores it in a normalized SQLite database, and performs SQL
analysis.

## Requirements

- Python 3
- pandas
- requests
- beautifulsoup4

## How to Run

```bash
python scraper.py
python queries.py
python pandas_verify.py
